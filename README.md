# Portafolio personal

Proyecto desarrollado como parte del Sprint 4 del programa de Desarrollo Web de TripleTen.

El sitio funciona como un portafolio personal responsive en el que presento mi perfil, habilidades, proyectos y medios de contacto.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Diseño responsive
- Git y GitHub
- Figma

## Características

- Diseño adaptado para escritorio, tablet y dispositivos móviles.
- Media queries para diferentes tamaños de pantalla.
- Imágenes responsivas.
- Degradados creados con CSS.
- Estados hover en enlaces.
- Tipografías locales.
- Estructura HTML semántica.
